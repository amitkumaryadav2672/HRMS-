# HRMS - Human Resource Management System

A simple console-based HRMS application built using Core Java and MySQL.

## Requirements
- Java JDK 17+
- MySQL Server (Database: `hrms_db`)

## Project Structure
- `src/com/hrms/HRMSApp.java`: Main application logic, menus, and user input.
- `src/com/hrms/Database.java`: MySQL database connection and all SQL operations.
- `schema.sql`: Database tables schema.
- `lib/mysql-connector-j-8.3.0.jar`: MySQL JDBC connector.

## How to Run
- Run `compile.bat` to compile.
- Run `run.bat` to start the application.
